# Project Blueprint

## Overview

This project is a Korean Lotto Number Generator. It provides a simple and visually appealing interface for users to generate random lottery numbers.

## Project Outline

### Style and Design

*   **Layout:** A clean, centered layout.
*   **Colors:** A modern color palette with a vibrant look and feel.
*   **Typography:** Expressive and easy-to-read fonts.
*   **Interactivity:** Smooth animations and effects on button clicks and number generation.
*   **Visual Effects:** Use of drop shadows to create a sense of depth.

### Features

*   **Number Generation:** Generates 6 unique random numbers between 1 and 45.
*   **Bonus Number:** Generates 1 bonus number.
*   **Display:** Displays the generated numbers in a clear and organized way.
*   **"Generate" Button:** A button to trigger the number generation.
