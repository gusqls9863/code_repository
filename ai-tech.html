인공지능 이미지 분류 기술

1. Teachable Machine 개요

본 사이트의 이미지 분류기는 Google에서 개발한 Teachable Machine 기술을 기반으로 합니다. 이는 복잡한 코딩 없이 머신러닝 모델을 학습시킬 수 있는 웹 기반 도구로, 전이 학습(Transfer Learning) 방식을 사용하여 높은 정확도를 유지합니다.

2. 브라우저 기반 AI (TensorFlow.js)

이미지 분석은 서버가 아닌 사용자의 브라우저에서 직접 수행됩니다. TensorFlow.js 라이브러리를 통해 모델을 실시간으로 실행하므로 별도의 이미지 업로드 과정이 필요 없으며, 이는 사용자 프라이버시 보호에 탁월한 구조입니다.

3. 딥러닝 모델의 이해

강아지와 고양이 분류 모델은 수만 장의 이미지를 CNN(합성곱 신경망) 구조를 통해 학습되었습니다. 이미지의 색상, 패턴, 질감을 분석하여 가장 일치하는 클래스를 확률 점수로 보여줍니다.
